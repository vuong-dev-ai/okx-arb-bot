Các bước thiết lập
1
Đăng ký Oracle Cloud

Vào cloud.oracle.com → Start for free. Điền thông tin và chọn Home Region: Singapore — quan trọng, không thay đổi được sau khi tạo.

—
Chọn Singapore (ap-singapore-1) để latency thấp nhất với OKX. Nếu chọn US thì ping tăng 150–200ms.
2
Tạo VM Instance

Vào Compute → Instances → Create Instance và cấu hình như sau:

Oracle Console — Cấu hình Instance
Name okx-bots-server Image Ubuntu 22.04 (Canonical) Shape VM.Standard.A1.Flex ← Always Free OCPU 4 Memory 24 GB Public IP Assign a public IPv4 address ✓ SSH Key Generate a key pair → tải về .key

Giữ file .key cẩn thận — mất file là mất quyền SSH vào server.

3
Mở Firewall

Oracle mặc định chặn tất cả port ngoài 22. Cần mở thêm port cho web dashboard.

Trên Oracle Console: Networking → VCN → Security Lists → Add Ingress Rules

Ingress Rule — Oracle Console
Source CIDR 0.0.0.0/0 Protocol TCP Port Range 5000-5001 ← port arb-bot và trend-bot

Trên server (sau khi SSH vào) — Ubuntu có thêm firewall nội bộ:

bash
# Mở port trong iptables nội bộ sudo iptables -I INPUT -p tcp --dport 5000 -j ACCEPT sudo iptables -I INPUT -p tcp --dport 5001 -j ACCEPT sudo apt install iptables-persistent -y sudo netfilter-persistent save
4
SSH từ Windows

Lấy IP public từ Oracle Console. Sau đó SSH vào server qua PowerShell:

PowerShell — Windows
# Đặt permission đúng cho file key icacls "C:\path\to\your-key.key" /inheritance:r /grant:r "$env:USERNAME:(R)" # SSH vào server ssh -i "C:\path\to\your-key.key" ubuntu@<IP_SERVER>
5
Cài môi trường trên server
bash — Ubuntu Server
# Cập nhật hệ thống sudo apt update && sudo apt upgrade -y # Python, pip, git sudo apt install python3 python3-pip python3-venv git -y # PM2 để quản lý process sudo apt install nodejs npm -y sudo npm install -g pm2
6
Upload code lên server

Cách A — SCP (không cần GitHub, upload trực tiếp):

PowerShell — Windows
# Copy từng bot lên server scp -i "your-key.key" -r "D:\PYTHON\okx-arb-bot" ubuntu@<IP>:~/ scp -i "your-key.key" -r "D:\PYTHON\okx-trending-bot" ubuntu@<IP>:~/ scp -i "your-key.key" -r "D:\PYTHON\telegram_gateway" ubuntu@<IP>:~/

Cách B — Git (nếu code đã đẩy lên GitHub):

bash — Server
git clone https://github.com/username/okx-arb-bot.git git clone https://github.com/username/okx-trending-bot.git git clone https://github.com/username/telegram_gateway.git
7
Cài dependencies & cấu hình .env
bash — Server
# Cài requirements cho từng bot cd ~/okx-arb-bot && pip3 install -r requirements.txt cd ~/okx-trending-bot && pip3 install -r requirements.txt cd ~/telegram_gateway && pip3 install -r requirements.txt

Tạo file .env trên server (không commit file .env lên git):

bash — Tạo .env trên server
# Copy .env từ local lên server scp -i "your-key.key" "D:\PYTHON\okx-arb-bot\.env" ubuntu@<IP>:~/okx-arb-bot/ scp -i "your-key.key" "D:\PYTHON\okx-trending-bot\.env" ubuntu@<IP>:~/okx-trending-bot/
8
Chạy bot với PM2
bash — Server
# Khởi chạy cả 3 bot pm2 start "python3 app.py" --name okx-arb-bot --cwd ~/okx-arb-bot pm2 start "python3 app.py" --name okx-trend-bot --cwd ~/okx-trending-bot pm2 start "python3 gateway.py" --name telegram-gateway --cwd ~/telegram_gateway # Lưu config — tự động restart khi server reboot pm2 startup # chạy lệnh mà PM2 in ra pm2 save
—
Sau pm2 startup, PM2 sẽ in một lệnh sudo env ... — copy và chạy lệnh đó để hoàn tất thiết lập auto-start.
Quản lý với PM2
pm2 status
Xem trạng thái tất cả bot — online / errored / stopped
pm2 logs
Xem log realtime của tất cả bot
pm2 logs okx-arb-bot
Log của riêng arb-bot (thêm --lines 200 để xem nhiều hơn)
pm2 restart all
Restart tất cả bot cùng lúc sau khi update code
pm2 restart okx-arb-bot
Restart riêng 1 bot theo tên
pm2 stop all
Dừng tất cả bot (không xóa khỏi PM2)
pm2 monit
Dashboard realtime: CPU, RAM, restart count từng process
pm2 flush
Xóa toàn bộ log files của PM2
Script deploy nhanh
deploy.ps1 — chạy mỗi khi sửa code

Lưu file này tại D:\PYTHON\deploy.ps1. Mỗi lần sửa xong, chỉ cần chạy 1 lệnh.

PowerShell — deploy.ps1
param([string]$bot = "all") $SERVER = "ubuntu@<IP_SERVER>" $KEY = "C:\path\to\your-key.key" function Deploy($name, $path) { Write-Host "→ Deploy $name..." scp -i $KEY -r "D:\PYTHON\$path" "${SERVER}:~/" ssh -i $KEY $SERVER "pm2 restart $name" } if ($bot -eq "all") { Deploy "okx-arb-bot" "okx-arb-bot" Deploy "okx-trend-bot" "okx-trending-bot" Deploy "telegram-gateway" "telegram_gateway" } else { Deploy $bot $bot } Write-Host "✓ Deploy hoàn tất"
Cách dùng
# Deploy tất cả bot .\deploy.ps1 # Chỉ deploy arb-bot .\deploy.ps1 okx-arb-bot # Chỉ deploy trend-bot .\deploy.ps1 okx-trend-bot
