EMA Trend
Following on
OKX Perpetuals

Chiến lược theo xu hướng trung hạn khung 4H dùng giao cắt EMA 21/55 kết hợp ADX ≥ 20. Kích thước vị thế tính theo ATR risk model — mỗi trade rủi ro tối đa 1.5% balance.

01
Chiến lược
Luồng thực thi

Bot quét tín hiệu sau mỗi nến 4H mới đóng — không spam REST API theo interval cố định.

1Detect nến 4H mới đóng → 2Tính EMA / ADX / ATR + 1D filter → 3EMA crossover + volume confirm → 4Mở LONG / SHORT với ATR-sized position → 5Partial TP 50% @ 2×ATR + trailing stop → 6Thoát khi stop hit hoặc EMA reverse
Điều kiện vào lệnh
Long EMA21 cắt lên EMA55 · ADX ≥ 20 · Volume nến > TB 20 nến · Trend 1D = UP
Short EMA21 cắt xuống EMA55 · ADX ≥ 20 · Volume nến > TB 20 nến · Trend 1D = DOWN

Bộ lọc correlation ngăn mở 2 vị thế cùng chiều trong nhóm: {BTC, ETH} · {SOL, AVAX, NEAR} · {ARB, OP} · {DOGE, PEPE, FLOKI}. ATR% > 8% → bỏ qua tín hiệu.

02
Tính năng
Volume Confirmation
Mới

Signal chỉ kích hoạt khi volume nến crossover vượt trung bình 20 nến trước. Lọc false breakout thiếu conviction.

1D Trend Filter
Mới

Kiểm tra EMA21/55 daily trước khi vào lệnh. LONG chỉ khi 1D = UP, SHORT chỉ khi 1D = DOWN. Tránh giao dịch ngược macro trend.

ATR% Volatility Filter
Mới

Bỏ qua coin có ATR% > 8% — volatility quá cao khiến stop loss quá xa, rủi ro/phần thưởng không hợp lý.

EMA Reverse Exit
Mới

Đóng vị thế khi EMA cắt ngược chiều ngay cả khi trailing stop chưa bị chạm. Thoát sớm khi trend đảo chiều.

Partial Take-Profit
Mới

Tự động đóng 50% vị thế khi lợi nhuận đạt ≥ 2×ATR. Phần còn lại tiếp tục với trailing stop. Chỉ kích hoạt 1 lần.

Correlation Filter
Mới

Ngăn mở nhiều vị thế cùng chiều trên coin tương quan cao. Đang LONG BTC → không LONG ETH. Giảm rủi ro tập trung.

ATR Position Sizing
Core

notional = (balance × 1.5%) / (2×ATR / price). Coin volatile → notional nhỏ hơn. Coin ổn định → notional lớn hơn. Cap tại 25% balance × leverage.

ATR Trailing Stop
Core

Ratchet theo trail_anchor ± 3×ATR. LONG: anchor = max giá đạt, stop = anchor − 3×ATR. Stop chỉ dịch chuyển có lợi.

WebSocket Realtime Prices
Core

Mark price cập nhật sub-second qua OKX WebSocket. PnL và trailing stop refresh mỗi 2 giây. Fallback REST nếu WS stale > 15s.

Bayesian Coin Scoring
Core

Sau mỗi trade đóng, cập nhật per-coin stats. score = avg_roi × n/(n+3). Coin score thấp bị bỏ qua trong scan kế tiếp.

State Persistence + Reconcile
Core

Vị thế lưu vào state.json sau mỗi thay đổi. Khi restart, bot restore và reconcile với OKX để xóa phantom positions.

OKX Verify After Close
Bảo mật

Sau mỗi lệnh đóng, query lại OKX xác nhận vị thế đã biến mất trước khi xóa local state. Tránh phantom positions.

Telegram Notifications
Mới

Thông báo khi mở vị thế (side/entry/stop), đóng vị thế (PnL), bot crash. Cấu hình qua TELEGRAM_TOKEN + TELEGRAM_CHAT_ID.

Auto-Restart on Crash
Mới

Bot tự restart tối đa 3 lần nếu crash với delay 30s. Sau 3 lần thất bại mới dừng hẳn. Gửi Telegram alert mỗi lần.

Cấu hình

Tạo file .env trong thư mục bot. Telegram là tùy chọn — bot chạy bình thường nếu không cấu hình.

# Bắt buộc — OKX API OKX_API_KEY=your_api_key OKX_SECRET_KEY=your_secret_key OKX_PASSPHRASE=your_passphrase OKX_SIMULATED=false # true = demo account # Tùy chọn — Telegram alerts TELEGRAM_TOKEN=123456:ABC-DEF... TELEGRAM_CHAT_ID=-100123456789 BOT_NAME=TREND

Bot chạy trên SWAP perpetuals. Cần bật quyền Trade trên OKX API key. Margin mode: Isolated. Position mode: One-way.
